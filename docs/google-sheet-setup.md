# 結帳系統 → Google Sheet 串接

## 架構
```
網頁/PWA 結帳表單 ──POST(JSON)──▶ GAS Web App (gas/Code.gs) ──▶ Google Sheet
                                   │  驗證 + 依「菜單」重算金額
                                   │  LockService 產生訂單編號 GHyyMMdd-001
                                   │  clientId 冪等（重送不重複）
                                   └─ 寄信通知店家 / 每日 21:30 日報
```
工作表：`訂單`（一單一列，狀態下拉）、`訂單明細`（一品項一列）、`菜單`（價格與上架開關）。

## 部署步驟（約 10 分鐘）
1. 新建 Google 試算表，命名「金禾鍋貼訂單」。
2. 選單 **擴充功能 → Apps Script**，把 `gas/Code.gs` 全部貼進 `Code.gs`。
   （要用 `appsscript.json`：專案設定 → 勾「顯示 appsscript.json」後貼上。）
3. 儲存後在編輯器執行一次 `setup`，授權（Google 會警告「未驗證」→ 進階 → 前往）。
4. 專案設定 → **指令碼屬性** → 若 Apps Script 是獨立建立（不是從試算表的「擴充功能」開的），新增 `SHEET_ID` = 試算表網址 `/d/` 與 `/edit` 之間那串 ID；再新增 `NOTIFY_EMAIL` = 你的 Email（不設就不寄信）。
5. 重新整理試算表，選單 **金禾訂單 → 安裝每日報表**。
6. **部署 → 新增部署作業 → 網頁應用程式**：執行身分「我」、存取權「所有人」→ 複製 `…/exec` 網址。
7. 把網址貼進 `index.html` 的 `const ORDER_API = '';`，推上 GitHub Pages。
8. 前台下一筆測試單，確認試算表出現資料。

> 之後修改 Code.gs 要 **部署 → 管理部署作業 → 編輯 → 新版本**，網址才會沿用。

## 日常使用
- 到 `訂單` 分頁用「狀態」下拉更新：新訂單 → 製作中 → 可取餐 → 已完成 / 已取消。
- 改價格、下架商品：直接改 `菜單` 分頁（勾選＝上架）。**網站畫面上的價格仍寫在 index.html**，兩邊要一起改，否則客人看到的價格與實收不同（以試算表為準）。
- 狀態查詢 API：`<網址>?action=status&orderNo=GH261116-001&phone=0912345678`。

## 安全提醒
- Web App 網址是公開的，所以後端不信任前端金額、擋公式注入、有 honeypot 與長度限制；但沒有登入，仍可能被灌垃圾單。若發生，可加 reCAPTCHA 或 LINE 登入。
- 試算表含顧客電話與地址，請勿分享給不相關的人。

## 測試
`node tests/gas.test.js`：以記憶體版試算表模擬驗證下單、重算、冪等、防注入等。
